# Esoteric Programming Languages

[English version below](#english-version)

## Opis projektu

Projekt zawiera implementacje wybranych algorytmów matematycznych w różnych ezoterycznych językach programowania (esolangs).
Cały kod został napisany bez uzycia SI, jedynie z dokumentacji danego języka.

## Implementowane algorytmy

Dla każdego języka realizowany jest zestaw następujących algorytmów:

1. Ciąg Fibonacciego
2. Największy Wspólny Dzielnik (NWD)
3. Sprawdzanie liczby pierwszej
4. Rozkład na czynniki pierwsze
5. Silnia

## Języki

- [ArnoldC](./ArnoldC/README.md) – język oparty na cytatach z filmów z udziałem Arnolda Schwarzeneggera.
- [LolCode](./LolCode/README.md) - język zainspirowany memami internetowymi z udziałem kotów (lolcats).

# Esoteric Programming Languages

## Project Overview

This repository contains implementations of selected mathematical algorithms in various esoteric programming languages (esolangs).
The entire code was written without the use of AI, relying solely on the language's documentation.

## Implemented Algorithms

For each language, the following set of algorithms is implemented:

1. Fibonacci sequence
2. Greatest Common Divisor (GCD)
3. Prime number check
4. Prime factorization
5. Factorial

## Languages

- [ArnoldC](./ArnoldC/README.md) – A programming language based on one-liners from Arnold Schwarzenegger movies.
- [LolCode](./LolCode/README.md) - A programming language inspired by internet memes featuring cats (lolcats).
